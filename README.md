# Petalswift

Luxury flowers and composed bouquets for New York City.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Vercel-ready

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

1. Create a GitHub repository named `petalswift` (or similar).
2. Push this project to that repository.
3. In Vercel project **petal** → **Settings** → **Git**, connect the repo (or import it as a new project and move the `petalswift.com` domain over).
4. Deploy. Production URL: [https://www.petalswift.com](https://www.petalswift.com).
